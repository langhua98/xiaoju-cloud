# 小橘推送（iPhone App）

把小橘云盘文件夹里改过的代码，在手机上提交、推送到 GitHub。和「小桔备份」（`ios/`）无关。

- 设置里填：小橘云盘地址、`xa_` 令牌（只读即可）、GitHub 令牌（目标仓库 Contents 可写）。令牌存在钥匙串。
- 「推送任务」：云盘文件夹 → 仓库 / 分支 / 仓库里的目录。可以浏览云盘选文件夹、从自己的仓库里选。
- 点一个任务：自动检查改动，列出改了哪些文件（新增 / 修改，+加 −减 行数）；点文件看具体改了哪几行（绿加红减）。
- 提交说明自动生成（摘要 + 文件清单），可以改；点「提交并推送」，一次提交推到分支。
- 只推内容变了的文件（云盘 sha256 + git blob sha 比较）；云盘删掉的文件不会在 GitHub 删除；没改动不提交；不强推。

不打开手机也想自动同步：用 `tools/cloud-sync`（GitHub Actions 定时跑）。

## 编译和安装

推送 `pushapp/` 的改动后，`.github/workflows/pushapp.yml` 在 GitHub 的 Mac 机器上编译，
没签名的 `.ipa` 发布到 Release「pushapp」。用 SideStore（自己的 Apple ID）或自己的证书签名后安装。
