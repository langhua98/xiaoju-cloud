# 小桔模型接口说明

网页地址：`https://langhua98.github.io/xiaoju-cloud/xiaoju-web/`

把这个网页放进应用里的网页视图（苹果上是 `WKWebView`），就能用下面的接口控制小桔。
所有接口都挂在网页的 `window.xiaoju` 上。

## 一、嵌入时的网址参数

| 参数 | 作用 | 例子 |
|---|---|---|
| `ui=0` | 隐藏底部按钮和顶部提示，只留小桔 | `?ui=0` |
| `bg=transparent` | 背景透明，叠在应用自己的界面上；也可以写颜色 `bg=ffffff` | `?ui=0&bg=transparent` |
| `view=full / half / face` | 开场镜头：全身 / 半身 / 脸部 | `&view=half` |
| `motion=动作名` | 加载完自动做一个动作 | `&motion=wave` |
| `face=表情名` | 开场表情 | `&face=happy` |

应用里推荐用：`https://langhua98.github.io/xiaoju-cloud/xiaoju-web/?ui=0&bg=transparent&view=half`

## 二、指令（应用 → 小桔）

统一入口是 `xiaoju.send(指令)`，指令是一个对象或一段 JSON 文字。

| 指令 | 作用 |
|---|---|
| `{cmd:'play', name:'wave'}` | 做一个动作。可加 `loop:true` 一直循环、`reps:2` 播两遍、`speed:1.2` 速度、`face:'happy'` 表情 |
| `{cmd:'sequence', list:['wave','bow']}` | 依次做一串动作 |
| `{cmd:'emote', name:'greet'}` | 按“意思”做动作，见下面的快捷方式表 |
| `{cmd:'stop'}` | 停下，回到待机 |
| `{cmd:'state', name:'talking'}` | 助手状态：`idle` 待机、`listening` 在听、`thinking` 在想、`talking` 在说 |
| `{cmd:'face', name:'happy', seconds:3}` | 换表情，`seconds` 秒后自动恢复（不写就一直保持） |
| `{cmd:'mouth', value:0.6}` | 嘴巴张开程度 0~1。播语音时按音量每秒发 20~30 次，嘴型就跟着声音动 |
| `{cmd:'speak', on:true, seconds:5}` | 不想算音量时用：嘴巴自动张合，`seconds` 秒后停 |
| `{cmd:'view', name:'half'}` | 切镜头：`full` / `half` / `face` / `auto`（自动旋转开关） |
| `{cmd:'turn', deg:90}` | 镜头绕小桔转多少度 |
| `{cmd:'ui', show:false}` | 显示或隐藏按钮 |
| `{cmd:'background', color:'transparent'}` | 换背景 |
| `{cmd:'list'}` | 让网页回一条 `list` 事件，里面是全部动作、快捷方式、表情的名字 |

也可以直接调用函数（效果相同）：
`xiaoju.play('wave')`、`xiaoju.sequence([...])`、`xiaoju.emote('greet')`、`xiaoju.stop()`、
`xiaoju.state('thinking')`、`xiaoju.face('happy', 3)`、`xiaoju.mouth(0.6)`、`xiaoju.speak(true, 5)`、
`xiaoju.view('half')`、`xiaoju.turn(90)`。

`xiaoju.play(...)` 会返回一个承诺，动作做完时完成，结果是 `{name, finished}`；
`finished` 为 `false` 表示中途被别的动作打断了。

## 三、事件（小桔 → 应用）

| 事件 | 什么时候发 | 带的内容 |
|---|---|---|
| `ready` | 模型加载好，可以发指令了 | `motions` 动作列表 |
| `motionstart` | 动作开始 | `name`、`duration`（秒，循环动作为空） |
| `motionend` | 动作结束 | `name`、`finished` |
| `face` | 表情变了 | `name` |
| `state` | 助手状态变了 | `name` |
| `tap` | 用户点了小桔 | `part`：`head` 头 / `body` 身体 |
| `list` | 回应 `list` 指令 | `motions`、`emotes`、`faces` |
| `error` | 出错（动作名写错、文件加载失败等） | `message` |

每条事件都是这样的对象：`{source:'xiaoju', type:'motionend', name:'wave', finished:true}`

事件会同时发往：
- 苹果应用：`window.webkit.messageHandlers.xiaoju`
- 网页里自己监听：`xiaoju.on('motionend', fn)`，`xiaoju.on('*', fn)` 收全部
- 外层网页（用 iframe 嵌入时）：`window.parent.postMessage`
- React Native：`window.ReactNativeWebView`；安卓：`window.XiaojuAndroid`

在指令发出前模型还没加载好也没关系，指令会排队等加载完再执行。

## 四、苹果应用里怎么接（Swift）

```swift
import WebKit

final class XiaojuView: NSObject, WKScriptMessageHandler {
    let webView: WKWebView

    override init() {
        let config = WKWebViewConfiguration()
        webView = WKWebView(frame: .zero, configuration: config)
        super.init()
        // 收小桔发来的事件
        config.userContentController.add(self, name: "xiaoju")
        // 背景透明，叠在自己的界面上
        webView.isOpaque = false
        webView.backgroundColor = .clear
        webView.scrollView.isScrollEnabled = false
        let url = URL(string: "https://langhua98.github.io/xiaoju-cloud/xiaoju-web/?ui=0&bg=transparent&view=half")!
        webView.load(URLRequest(url: url))
    }

    // 发指令：send(["cmd": "play", "name": "wave"])
    func send(_ command: [String: Any]) {
        guard let data = try? JSONSerialization.data(withJSONObject: command),
              let json = String(data: data, encoding: .utf8) else { return }
        webView.evaluateJavaScript("window.xiaoju && xiaoju.send(\(json))")
    }

    // 收事件
    func userContentController(_ controller: WKUserContentController, didReceive message: WKScriptMessage) {
        guard let event = message.body as? [String: Any],
              let type = event["type"] as? String else { return }
        switch type {
        case "ready":     send(["cmd": "emote", "name": "greet"])
        case "tap":       send(["cmd": "emote", "name": "shy"])
        case "motionend": break   // 动作做完了，可以接下一步
        default:          break
        }
    }
}
```

聊天助手的常见用法：

```swift
xiaoju.send(["cmd": "state", "name": "listening"])   // 用户开始说话
xiaoju.send(["cmd": "state", "name": "thinking"])    // 等模型回答
xiaoju.send(["cmd": "state", "name": "talking"])     // 开始播语音
xiaoju.send(["cmd": "mouth", "value": 0.7])          // 播语音时按音量反复发
xiaoju.send(["cmd": "state", "name": "idle"])        // 说完了
xiaoju.send(["cmd": "emote", "name": "laugh"])       // 回答里带情绪时
```

## 五、动作名

**动作**：`wave` 挥手、`wave_big` 用力挥手、`nod` 点头、`shake` 摇头、`bow` 鞠躬、`curtsey` 提裙礼、
`shrug` 耸肩、`talk` 说话、`spin` 转圈、`jump` 跳一跳、`peekaboo` 躲猫猫

**心情**：`cheer` 欢呼、`laugh` 大笑、`sad` 难过、`cry` 哭、`scared` 害怕、`upset` 抓狂、`angry` 生气、`think` 思考

**日常**：`yawn` 伸懒腰、`phone` 打电话、`comb` 梳头、`drink` 喝水、`cold` 好冷、`cat` 学猫咪、`jacks` 开合跳

**舞蹈**：`dance_loop` 小舞步、`charleston` 查尔斯顿、`charleston_f` 摇摆舞、`charleston_x` 花式舞步、
`ballet` 芭蕾、`chicken` 小鸡舞、`macarena` 玛卡雷纳、`mickey` 米奇舞

**表情**：`neutral` 默认、`happy` 开心、`angry` 生气、`sad` 难过、`surprised` 惊讶、`relaxed` 放松、`shy` 害羞、`wink` 眨眼

## 七、以后怎么加动作

1. 把 `.vrma` 动作文件放进 `motions` 文件夹。
2. 在 `index.html` 的动作表 `MOTIONS` 里加一行，例如
   `hello: { label: '你好', icon: '👋', group: 'act', face: 'happy' },`
   按钮会自动出现，接口也能直接用 `hello` 这个名字。
3. 如果替换了已有的动作文件，把 `MOTION_VER` 加一，手机才不会继续用旧文件。

也可以不改网页，运行时临时加：
`xiaoju.register('hello', { url: 'https://……/hello.vrma', label: '你好', group: 'act' })`

## 八、动作数据来源

动作来自开源数据集 open-vrma：Quaternius 动画库（CC0）和 CMU 动作捕捉数据库。
使用 CMU 数据需要保留这句致谢（网页“视角”页里已经有）：

> The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

每个动作的来源和授权写在 `motions` 文件夹里同名的 `.motion.json` 文件中。
